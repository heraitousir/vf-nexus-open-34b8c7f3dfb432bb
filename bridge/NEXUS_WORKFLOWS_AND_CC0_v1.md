# NEXUS CONSUMER ORIGINAL GAME, SCENE, MEMORY AND CC0 REFERENCE GUIDE v1

## PERSONAL GAME MECHANICS MEMORY - user's OWN games only
After a local Godot game passes VERIFY GODOT RUNTIME, Nexus stores SHA-256
fingerprints and immutable GDScript source examples in that user's LOCAL
Desktop/projects/.nexus-mechanic-memory folder. This library accumulates
across 10, 15 or many more projects; it is not shared with other consumers.
In Game Builder, enter an original GAME NAME and NEW GAME IDEA, click
SEARCH MY PAST GAME MECHANICS, then CREATE USING MY GAME MEMORY. Nexus
creates a fresh playable starter and stages matching prior source plus a
REUSE-PLAN.txt under game/nexus-memory-suggestions. The code remains inert
until the local creator (and optionally their ChatGPT with explicit source
sharing) adapts it to the new nodes, scene layout, input map and game rules.
Importing a third-party game requires a separate rights confirmation.
Run VERIFY GODOT RUNTIME again after integration, then test real gameplay.
The GitHub bridge does NOT silently upload this private mechanics library,
and ChatGPT cannot read it without user-authorized sharing. This is source
recall and reuse planning, NOT neural training or autonomous game completion.

## Original in-app scene editor
Use the SCENES page to open an existing project or create a new original 3D World.
The actual WPF Viewport3D allows original primitive meshes, colors, positions,
dimension edits, object selection, camera orbit, undo/redo and saved JSON. The
GODOT 3D STAGE export is an editable separate Godot scene, not a replacement for
a previously-authored 2D game. Any downloaded research model is excluded.

## Safe paired creative commands
Use fresh unique request IDs and the real device ID as taught in the main guide.

- scene_create: {"type":"scene_create","name":"My Original 3D World"}.
  Creates a fresh editable 3D scene only; does not claim a rendered game.
- foreman_production: {"type":"foreman_production","name":"Mossy Tree Study","prompt":"Design an original mossy old tree model with branching details and rough bark."}.
  Foreman routes a bounded request to REAL Blender model authoring, Nexus scene
  creation, Godot starter, or Blender->Godot original GLB handoff based on text.
  Unavailable or manual Maya, 3ds Max, Unreal adapters are NOT marked complete.
- game_qa: {"type":"game_qa","name":"My New Game"}.
  Runs installed Godot headless import and 120 engine frames, saves local logs
  and source hashes, and only claims the tests actually passed.

## Verified personal learning
An original Blender model passes actual geometry, preview and quality-report
checks before the customer's local Nexus stores its technique hints. Later
related model prompts can reuse allowlisted techniques. This is local retrieval,
NOT fine-tuning, and never copies model vertices or private assets from others.

## CHROME CC0 REFERENCE RESEARCH
The Chrome CC0 REFERENCES page uses the official Poly Haven API for a vetted
model catalog, opens official Poly Haven pages in installed Google Chrome, and
only downloads original CC0 assets when the PC owner confirms. It also links
ambientCG's CC0 reference library. Downloaded model files and provenance are
stored outside Desktop/projects under the app's isolated reference-research
folder. NEVER import these files, meshes, characters or textures into a scene,
blend model, Godot game or redistributable project. Study shape and proportions
and build your own original geometry. The browser does NOT scrape arbitrary
sites; unsupported licenses and unknown hosts are blocked.
